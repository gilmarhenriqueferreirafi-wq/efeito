=====================================================================
 ESFERAS 3D NO TERMINAL  -  COMANDOS
 arquivo: esfera.py   |   roda no Windows 10+ (cmd ou PowerShell)
=====================================================================

COMO RODAR
----------
  cd ate a pasta do arquivo
  python esfera.py

  se nao achar o python:
     py esfera.py
     python3 esfera.py

  Ctrl+C  ->  sai


ARGUMENTOS
----------
  numero         quantas esferas (1 a 8)         padrao: 2
  --metaball     modo fusao (as esferas se derretem juntas)
  --cores LISTA  lista de cores em hexadecimal
  -c LISTA       atalho para --cores
  LISTA solta    tambem funciona sem escrever --cores


EXEMPLOS
--------
  python esfera.py                     2 esferas solidas, cores padrao
  python esfera.py 1                   uma esfera so
  python esfera.py 3                   tres esferas
  python esfera.py 5                   cinco esferas
  python esfera.py 8                   maximo de esferas

  python esfera.py --metaball          fusao com 2 esferas
  python esfera.py 4 --metaball        fusao com 4 esferas
  python esfera.py --metaball 6        ordem nao importa
  python esfera.py 3 --cores "#ff0000,#00ff00"

  python esfera.py "#ff0000,#00ff00,#0000ff"
                                       cores sem escrever --cores
  python esfera.py -c "#f00,#0f0,#00f"
                                       forma curta (#rgb) repetida
  python esfera.py -c "ff8800;22ddaa"  ponto e virgula tambem vale
  python esfera.py -c fb2b2b,2b33fb    sem # tambem vale
  python esfera.py 4 -c "#00e5ff"      4 esferas, todas ciano (1 cor so)


CORES
-----
  formato: #rrggbb  (com ou sem #) ou #rgb
  separador: virgula ,  ou  ponto e virgula ;
  quantas cores quiser; se der menos que as esferas, as cores repetem em ciclo
  entre duas cores vizinhas a zona de fusao faz a mistura automaticamente

  exemplos prontos:
     "#ff2d2d,#2df0ff"                 vermelho e ciano
     "#f5a623,#f8333c,#662d91"         âmbar, vermelho, violeta
     "#0aff6e,#00b3ff,#ffe600"         verde acido, azul, amarelo
     "#ffffff"                         branco puro (so brilho)
     "#111111,#eeeeee"                 preto e cinza, estilo monitor antigo

  erro de cor: se escrever algo invalido ele imprime
     erro nas cores: cor invalida: 'zz'  (use #rrggbb)
  e nao abre nada. confira o # e os 6 digitos.


CORES PADRAO (sem passar nada)
------------------------------

  #ff3caa   magenta
  #3cf0c8   ciano
  #ffbe28   ambar
  #a05aff   violeta


PROMPT QUE MUDA DE COR (PowerShell)
-----------------------------------
  cd C:\caminho\da\pasta
  powershell -NoExit -Command "python esfera.py 4 --metaball"

  abrir ja com cores:
  powershell -NoExit -Command "python esfera.py -c '#ff0000,#00ff00'"


DICAS
-----
  - janela maior = esferas maiores, o tamanho sai do tamanho do console
  - o console precisa ser Windows 10 ou mais novo para as cores aparecerem;
    sem isso sai tudo cinza
  - se aparecerem quadrados ou simbolos no lugar das letras, troque a fonte do
    console para Consolas ou Cascadia Mono
  - quanto mais esferas, mais pesado; 8 em modo metaball cai o fps
  - o programa avisa no inicio: esferas, cores e modo (solidas ou metaball)

----------------
